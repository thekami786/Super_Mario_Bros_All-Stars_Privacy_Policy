# Super_Mario_Bros_All-Stars_Privacy_Policy

**Last Updated: June, 2026**

This Privacy Policy describes how your information is collected, used, and safeguarded when you play **Super Mario All-Stars** (the "Game"), hosted on GitHub Pages or distributed as a mobile application.

## 1. Information Collection

The Game is designed to be fully functional offline and does not require a user account.
* **Personal Information**: We do not collect, store, or share any personal identifying information (such as your name, email, or device details).
* **Game Progress**: Your high scores, character selections, and level progress are saved locally on your device using local storage (`SharedPreferences`). This data is stored entirely on your device and is never uploaded to external servers.

## 2. Third-Party Services

The Game may include integrations with third-party networks for analytics or advertising:
* **Google AdMob / Mobile Ads**: The Game uses Google Mobile Ads to deliver rewarded video advertisements for unlocking stages. Google AdMob may collect and use advertising identifiers (like Google Advertising ID or IDFA) to serve personalized advertisements. You can review AdMob's privacy policy at [https://policies.google.com/privacy](https://policies.google.com/privacy).

## 3. GitHub Pages Hosting

When playing the Game hosted on GitHub Pages, GitHub may collect standard web server access logs (including your IP address, browser type, and timestamp) for security and operational purposes. Please consult the GitHub Privacy Statement at [https://docs.github.com/site-policy/privacy/github-privacy-statement](https://docs.github.com/site-policy/privacy/github-privacy-statement) for more information.

## 4. Children's Privacy

The Game does not knowingly collect any personal information from children. All gameplay progress and metrics are kept strictly on the local device storage.

## 5. Contact Information

If you have any questions or feedback regarding this Privacy Policy, please contact the repository administrator on GitHub.
